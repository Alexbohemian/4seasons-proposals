# IMC Fund — Narrative Transition: Basic Components

**Author:** Pablo Muñoz Ledo, LIFT Economy — February 2026
**Project:** IMC Fund Fundraising / Storytelling Toolkit Project — Phase 2 ("Narrative transition")
**Client:** Indigenous Medicine Conservation Fund (IMC Fund / IMCF)

This folder is a markdown rendering of that deck so the redesign team can reference it without opening the PDF. The deck is almost entirely visual; where a slide carries no text, the visual content is described.

## What the document is

A brand/narrative-system proposal that moves IMC Fund from a cautious, monochrome, institution-only voice to a vivid, multi-voice visual language. It defines:

1. **A diagnosis** (Discovery recap): institutional voice dominates, imagery has been drained of color, and images are sometimes mismatched to the Bioculture they illustrate.
2. **A voice model**: four harmonized tiers of IMC Fund voices, from the Board outward to Elders and Community Leaders.
3. **A unifying metaphor**: "The Common Thread" — everything is interwoven and interdependent.
4. **A visual system**: for each of the five Biocultures (Ayahuasca, Iboga, Mushrooms, Peyote, Toad) a textile-inspired pattern plus a three-level color system (highlights, mid-tones, dark base), all blending out of a shared "common thread" pattern.
5. **Implementation examples**: one layout per Bioculture showing how pattern, palette, photography and typography combine.
6. **A proposed logo evolution.**

## Key takeaways for the redesign

- **Dark, textured base.** Every system slide sits on a near-black woven/grid texture (the common thread). Cover background samples at roughly `#170a23`; the pattern reads as a dark mesh, not flat black.
- **Five Biocultures, five sub-brands.** Ayahuasca (greens/orange/blue), Iboga (teal/orange/warm neutrals), Mushrooms (magenta/red/blue/green), Peyote (turquoise/terracotta/sand), Toad (blues/lavender/gold). Each has a distinct pattern and a 15–18 color system.
- **Three color roles per Bioculture.** *Highlights* (bright accents, used sparingly as vertical bars and stats), *mid-tone colors* (graphic elements, cards, callouts), *dark base colors* (backgrounds and pattern fills).
- **Two blend directions.** Pattern panels blend from the IMCF common-thread pattern into the Bioculture pattern either bottom-to-top or left-to-right.
- **Photography is real and vibrant.** No more desaturated or blurred imagery. Images must belong to the Bioculture and territory they illustrate, with people shown as named partners rather than generic illustrations.
- **Typography.** Bioculture names are set in a light serif (Cormorant-like); body and labels in a geometric sans (Barlow-like); the wordmark is a wide-tracked uppercase sans.
- **Voice hierarchy.** The institutional voice "sets the tone" but Biocultures, Partners, and Elders/Community Leaders should be visibly present as their own voices.
- **Logo.** Existing mark: a spiral of leaf/seed shapes around five dots, with four outlying leaves at the cardinal points. Proposed evolution keeps the same mark in dark green (`#36422d` sampled) with a wide-tracked four-line wordmark.
